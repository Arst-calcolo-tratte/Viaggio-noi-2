# Extra 300 € / mese

Mini web app per valutare e monitorare opportunità di entrata extra.

## Pubblicazione GitHub Pages

La pagina è disponibile al percorso `/guadagna/` della repository, se GitHub Pages è attivo per il repository.

## Funzioni

- obiettivo di 300 € mensili;
- calcolo guadagno netto e rendimento orario di un'attività;
- simulazione del fondo necessario per una futura auto;
- registro locale degli incassi tramite `localStorage`;
- alcune idee iniziali da testare, senza promesse di rendimento.

Il primo obiettivo è trasformare l'app in un vero cruscotto di opportunità: ricerca di lavori/servizi/prodotti compatibili, stima del tempo necessario, ROI e monitoraggio degli incassi reali.
